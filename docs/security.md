# 安全规范

## 凭据管理

- 仓库中**禁止**出现真实网址、账号、密码、Cookie、Token；
- 所有敏感配置通过环境变量注入，`.env` 已被 `.gitignore` 忽略；
- `.env.example` 只保留变量名占位，不填写任何真实值。

## 外部渠道

- 房源信息验证等能力**仅允许对接合法授权的渠道**；
- 渠道地址、凭据一律走配置注入，不硬编码；
- 渠道适配代码隔离在服务的 `infrastructure/` 内，不进入 `domain` 与公共包。

## 日志与脱敏

- 证件编码、业务件号、个人姓名等敏感字段在日志中必须脱敏；
- 脱敏工具统一由 `shared_logging` 与服务内 `security/masking.py` 提供（待实现）。

## 上传文件

- 上传文件必须经过类型、大小、内容校验（`security/file_validation.py`，待实现）；
- 文件只写入服务自身的 `storage/` 目录或配置的对象存储，禁止路径穿越。

## 审计

- 提取、验证等关键动作需记录审计事件（`security/audit.py`，待实现）；
- 审计内容本身也需脱敏。

## 错误处理

- 对外错误响应不泄露内部实现细节（堆栈、配置、渠道信息）。
